# GALXAI

GALX provides text and image generation APIs. Base URL: https://galx.ai/v1.
Authenticate with Authorization: Bearer YOUR_GALX_API_KEY.

Models: gpt-5.6-sol, gpt-5.6-terra, gpt-5.6-luna, openai-gpt-image-latest.
See https://galx.ai/models for supported features and https://galx.ai/pricing for prices.

POST /v1/images/generations accepts a text prompt. The default success response is
one binary image with an image/png, image/jpeg, or image/webp content type.
Set output_format to png, jpeg, or webp. Static images only; dimensions may vary.
JSON clients must specify response_format: b64_json or url, or Accept: application/json.
JSON contains created and data; each item has only b64_json or url. Download links
expire after one hour; URL results can also be self-contained data URLs.
Send Prefer: respond-async to receive a request ID and task_url. Poll that URL
with authentication or append /stream for status events.
Errors contain error.code, error.message, and error.request_id.

Public documentation: https://galx.ai/docs
API schema: https://galx.ai/api/openapi.json
Service status: https://galx.ai/status
