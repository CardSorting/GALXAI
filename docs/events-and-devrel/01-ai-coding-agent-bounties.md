## 1. Objective & Community Flywheel
Harness the rapidly growing ecosystem of AI coding agents (Cursor, Claude Code, Windsurf, Devin, Cline) by incentivizing open-source developers to create, test, and publish official GALXAI integrations and starter kits.

## 2. Bounty Categories & Rewards

| Bounty Track | Description | Reward Tier |
|---|---|:---:|
| **Track 1: IDE Agent Directives** | Create and test optimized `.cursor/rules`, `CLAUDE.md`, or Windsurf rules for popular fullstack frameworks. | **$100.00 Compute Grant + Merkle Proof Badge** |

## 3. Developer Referral Incentive Protocol
- Every registered developer gets a unique referral code.
- **Referrer Hook**: When a referred developer deposits $10.00+, the referrer receives a **$10.00 Compute Bonus** + a **5% perpetual rebate** on all referred token consumption.
- **Referee Hook**: The new developer receives the standard **$5.00 Free Live Compute Grant** immediately upon signup.
