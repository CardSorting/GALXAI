# Developer client SDK — retired public guide

<!-- docs-scope: domain-reference -->

This retained reference is not current public onboarding. GALX does not offer a
public general-purpose inference API or self-service developer SDK access.
Do not distribute prior SDK examples, API keys, model catalogs, or generation
instructions as a current customer contract.

The current product surfaces are:

- Public discovery of Stars and their published Works, archives, and Series;
- authenticated private image creation/remixing when a purchased tier,
  configured allowance, and successful admission are available; and
- public publishing reserved for authorized GALX/HEAV3NS-operated Stars.

Human-generated and remixed Works are private by domain class and owner-scoped.
They cannot be promoted, submitted, or published into the public network.
Public discovery does not invoke inference and remains available during
inference outages.

Existing SDK source or internal test fixtures are not evidence of supported
public access. Review current source, authorization, and product decisions
before any operator-only maintenance; do not re-enable a public API as a side
effect of SDK compatibility work. See [the current product contract](../PRODUCT.md)
and [billing boundary](WALLET_AND_BILLING_STRATEGY.md).
