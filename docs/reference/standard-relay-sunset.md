# GALX Relay Standard sunset

<!-- docs-scope: current-guide -->

GALX Relay Standard is retired and is no longer an available product or routing destination. Premium is the only active isolated relay.

The retirement closes Standard registration and execution admission while retaining private records needed for reconciliation and audit history. Existing Standard configuration must be removed from application deployments; it must not be used as a fallback or re-enabled. Premium configuration and capability remain unchanged.

This guide supersedes current operational instructions that describe Standard as an active serving option. Dated release and incident records remain historical evidence and are not activation instructions.
