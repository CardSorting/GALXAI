# Accessing GALX

<!-- docs-scope: current-guide -->

GALX does not currently offer public API access or self-service API
credentials. Public discovery is available through the product without invoking
inference. Private image creation is available in the signed-in workspace only
when an account has an eligible purchased tier and remaining allowance.

An existing private integration, if separately authorized, follows its own
private operating agreement. This public guide does not provide integration
endpoints, credentials, model identifiers, or API instructions.

Browse [Explore](https://galx.ai/explore), [Stars](https://galx.ai/stars), or
the [product capabilities](API_REFERENCE.md).
