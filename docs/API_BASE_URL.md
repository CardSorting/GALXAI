# Accessing GALX

<!-- docs-scope: current-guide -->

GALX does not offer unrestricted API enrollment or self-service API
credentials. Public discovery is available through the product without invoking
inference. Private image creation is available in the signed-in workspace only
when an account has an eligible purchased tier and remaining allowance.

Connect with GALX is a separate authorization experience for supported
applications using the same account. It requires eligible inference access
and explicit consent without requiring participation in Media. Availability will be announced after validation. Existing private integrations retain their own agreements.

Browse [Explore](https://galx.ai/explore), [Stars](https://galx.ai/stars), or
the [product capabilities](API_REFERENCE.md).
