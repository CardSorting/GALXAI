## 🧭 Architectural Principles

1. **Zero Client Refactoring**: Standard OpenAI API compatibility (`/v1/chat/completions`, `/v1/images/generations`, `/v1/models`).
2. **Sub-15ms Gateway Overhead**: Zero-allocation ring buffers, BroccoliDB L1 indexed tables, and non-blocking candidate selection.
3. **Anti-Sybil Integrity**: $10 minimum deposit proof with 50% instant match grant ($15 total usable credit) and 100% unspent balance refundability.
4. **Transparent Capacity Leveling**: Adaptive Hydraulic Headroom Cycling (P-AHT) with dynamic reliability weights and tenant affinity dispersion.
5. **Zero Data Retention**: Cryptographically provable memory zeroization, sliding-window streaming redaction, and SHA-256 Merkle tamper-evident custody chains.
6. **Continuous Autonomous Self-Healing**: Real-time SOC 2 drift evaluation with automated configuration remediation.
7. **Cemented Data Ruler & Egress Shield**: PostgreSQL remains the undisputed ruler of truth via Merkle epochs, while BroccoliDB provides a 0ms in-memory read shield and circuit breaker against runaway overages.
8. **Unpredictable Inference Resilience**: 3-Tier MLFQ fleet partitioning, ITL watchdog, Anti-Zombie Leash, and BroccoliDB resumable streams guarantee zero starvation, zero zombie quota waste, and zero truncation for frontier reasoning models with 2–3 minute unpredictable durations at 100,000 req/sec (ADR 0113).
9. **Deterministic Accountability for Uncertain Work**: Agents propose and report, the execution supervisor adjudicates transitions, the atomic ledger records accepted authority plus journal consequences, queues deliver authorized intents, and WebSocket/SSE expose retryable projections (ADR 0114).
10. **One Credential Authority**: Supabase PostgreSQL owns accepted shard state; BroccoliDB is a bounded-staleness projection, the journal is secret-free, and neither disk files nor edge KV receive durable raw credentials (ADR 0115).
