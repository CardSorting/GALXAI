### 🖥️ Local Presentation Quickstart

To run the offline 16:9 slide presentation locally:
```bash
# Open directly in your default browser on macOS:
open docs/investors/slides/index.html
```

**Controls**:
- `→` / `Space` / `PageDown`: Next slide
- `←` / `PageUp`: Previous slide
- `N`: Toggle speaker notes & talk track drawer
- `F`: Toggle full-screen mode
- `Home` / `End`: Jump to first / last slide
