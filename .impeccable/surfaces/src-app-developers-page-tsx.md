# Developer private preview

Mode: Operate. Preserve GALX's dark interface, Inter typography, restrained indigo controls and existing amber accent. The public home uses the existing galaxy image; no new image generation or visual-world replacement.

Images and Sites are the public products. The developer page explains the early preview, links directly to both public products, and offers verified-account signup followed by a project description and expected traffic. Signup never implies approval. Status states are loading, not requested, pending, approved, revoked, and unavailable. Approved participants have links to API keys/docs/playground and a private feedback form. Pending requests are durable and duplicate submissions do not replace their status. Feedback never renders in a public feed.

Navigation contains Images, Sites and Developer preview, with account access separate. Post-signup defaults to Images; explicit developer signup preserves /developers as the return destination. No invitation date, automatic contact or production reliability guarantee is promised.

Native labels, keyboard controls, visible focus, live status messages and 44px controls support desktop and phone use. Private fixture evidence lives under .impeccable/review/developer-preview. Production deployment and real invitations require their own rollout evidence.
