      Keyboard, persistence and setup

      This is a Linux desktop with familiar macOS-style windows and a Dock. Use Ctrl for browser shortcuts, Ctrl+Shift+C / V in Terminal, and Alt+Tab to switch windows. The browser may reserve some shortcuts outside full screen.

      Work in ~/workspace. Node.js, npm, Python, Git, curl and jq are available. Run galx-relay in Terminal for setup, start, status and stop commands. Install user tools with npm or a Python virtual environment. Each desktop has its own home directory, browser profile and network; it has no host filesystem or Docker socket.

      Closing the viewer keeps apps running. Stopping closes apps but preserves files and the browser profile. Deleting permanently removes them. A linked relay is a reference; configuring a desktop does not alter the currently serving worker.

      Delete this desktop?

      This permanently deletes its files, browser profile and saved setup. It does not delete a linked serving relay.

      Stop this desktop?

      Terminal, Chrome and any local relay will close. Unsaved work can be lost. Saved files and your Chrome profile remain available when you start again.
