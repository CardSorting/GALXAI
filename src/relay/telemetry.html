Task correlation & measurement guide

Send X-Galx-Task-Id: task-123 on related chat or image requests, then search for that ID. Each request returns X-Galx-Trace-Id. Task IDs accept up to 96 letters, digits, dots, underscores, colons or hyphens. Use an opaque identifier, not task content.

Duration starts when the relay receives the HTTP request and ends at the job's terminal state. The HTTP 202 response only acknowledges an asynchronous job. First output is the first forwarded output chunk; reasoning and keepalive events do not count. Chunks are not token counts. External tool execution and the full task runtime are not visible to this relay.

The store retains up to 500 requests for one hour and resets on restart. Percentiles use only the retained, filtered sample. Transport failures can originate in the network, provider or relay host; the waterfall supplies evidence rather than a definitive root cause. No prompts, outputs or credentials are captured.
