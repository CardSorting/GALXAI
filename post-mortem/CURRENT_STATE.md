## Regression boundaries

- Keep public image routes independent from developer approval storage; keep developer routes gated on both entry points.
- Verify sessions with the Auth service and uncached active-session authority, preserve owner filters, and verify private cache headers through the public hostname. Database errors and missing admin credentials must not become invalid-session responses.
- Async image status must read durable owner-scoped records, not a process-local queue. Receipt completion requires committed owned assets.
- Preserve original operation identity after a timeout or lost acknowledgement. A failed derived status does not prove no upstream side effect occurred.
- Preserve one controller owner, live worker resources, signing state and authoritative registry data during recovery. The new guardian must prove process-group termination before a replacement; an uncertain Docker mutation or admission receipt remains blocked/unknown rather than being replayed.
- Keep public artifacts re-encoded and public response fields allowlisted. Diagnostics belong in private authorized records.
