# Interrupted work incorrectly counted as provider failure

<!-- docs-scope: operational-record -->

INC-20261003-OUTCOMES is a SEV-3 correction following the bounded Connect acceptance. The provider exposes request outcomes, not a continuous healthy/unhealthy verdict. Runtime settlement converted every non-success, including cancellation, authorization interruption and crash recovery, into a provider failure. The earlier real cancellation contributed one retained failure. That historical observation is unchanged.

The correction preserves nullable provider evidence through the private execution function and central settlement. Confirmed completion is positive evidence; a reported provider availability failure is negative evidence; cancellation, transport loss, deadlines and local admission/authorization failures are neutral. Unknown execution records remain terminal and cannot authorize another dispatch. Request-level validation errors do not become account failures. Monitor warnings no longer act as an enable veto, and fresh credentials do not imply a healthy provider. Explicit credential rejection, expiry, revocation, live cooldown and admission limits remain authoritative.

Local verification passes 43 service tests, 51 connection tests, 26 Connect tests, 23 cooldown tests, 111 central authorization checks, 70 connection database checks, 43 isolated execution database checks including migration rollback, 94 general database checks and a production build. These fixture results are distinct from the installed recovery below.

The fixture now asserts denied deletion and retained account/desktop identity; production grants are unchanged.

No browser permission or database grant was widened.
